An interactive botanical and agricultural web experience visualizing the complete real-life developmental cycle of *Allium cepa* (Onion) across standardized **BBCH stages**, featuring fluid GSAP animations, high-resolution specimen imagery, anatomical telemetry, and interactive inspection loupe.

---

## 🌟 Key Features

- **BBCH Phenological Staging**: Detailed growth journey from dormant seed (BBCH 00), seedling loop formation (BBCH 09–10), leaf development (BBCH 14), bulb initiation & swelling (BBCH 41–45), bulb maturity & leaf fall (BBCH 48–49), through to umbel blooming & seed set (BBCH 65–75).
- **Interactive Visual Cockpit**:
  - Multi-angle views (Macro Zoom & Field Context).
  - Synchronized interactive stage dock with quick-jumping and arrow navigation.
  - Interactive Magnifier Loupe for microscopic inspection of epidermal structures.
  - Custom field photograph uploader for comparative field analysis.
- **Biometric Bento Telemetry**: Live metrics for each stage displaying seed caliber, bulb diameter, leaf blade counts, photoperiod thresholds, dry-matter accumulation, and sugar-to-water ratios.
- **Modern Glassmorphic UI**: Ambient cyber-botanical aesthetics with responsive typography, smooth scroll scrubbing powered by **GSAP** and **ScrollTrigger**.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/gaikwadsarthak272007/onion_revolution.git

# Navigate into the project folder
cd onion_revolution

# Open index.html in your default browser (or double click index.html)
```

### GitHub Pages (Free Hosting)
1. Go to repository **Settings** → **Pages**.
2. Select **Source**: `Deploy from a branch`.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save** to publish your live website!
